# The System

A 3D solar system / galaxy simulation built with Three.js. Open in a browser and fly.

## Controls

| Key | Action |
|---|---|
| WASD | Fly in free mode, walk in surface mode |
| Q/E | Fly up/down |
| Space | Jump (surface) |
| F | Land on planet (free mode) / Exit surface |
| E | Collect resources (surface) |
| R | Sprint (surface) |
| Tab | Cycle focus objects |
| Scroll | Adjust fly speed |
| Drag | Look around (free mode) |
| Escape | Exit surface / Close panels |
| = / - | Speed up / slow down time |
| B | Build panel |
| T | Research panel |
| L | Launch panel |
| G | Galaxy view |

## Features

- 10 planets with orbiting moons
- 27 nearby star systems with exoplanets
- 60,000-star spiral galaxy
- 15,000 background halo stars
- 5 globular clusters
- 30 colored nebula clouds
- Procedural terrain on rocky planets
- Resource gathering, building, research, and rocket launch mechanics
- New Game+ progression

## How to run

Open `index.html` in any modern browser. No server required.
